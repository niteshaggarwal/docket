Keyboard shortcuts

Docket for Windows can be used entirely from the keyboard. The same list is in the app under Settings > Keyboard shortcuts.

KeysWhat it does
Ctrl+NAdd a task (jump to the add bar)
Ctrl+DComplete the selected task
Ctrl+TAdd the selected task to My Day, or remove it
Ctrl+IMark the selected task important, or not
DeleteDelete the selected task (with Undo)
EnterOpen the task's details
EscClose the details
→ / ←Expand or collapse subtasks
Ctrl+FSearch
Ctrl+LNew list
Ctrl+R or F5Refresh

In the add bar, quick-add words set the date and priority, and / opens the commands.

On this documentation site, press / to search.
