Set up

Choose a setup

Docket keeps your tasks in Vikunja, an open-source task server, and adds the Docket apps and an AI connector on top. You can run it three ways. All three give you the same apps and the same features.

Claude Desktop, Claude Code, local models and the Docket apps work with every setup.

#Windows PC

Download the Windows zip from Releases, right-click install.ps1 and choose Run with PowerShell. It installs everything for your Windows account, without admin rights. Full guide, including what each question means: Windows PC.

#If the server stops

The apps, the CLI and the AI connector restart a stopped server on your PC by themselves, and Windows checks it every 5 minutes as a failsafe. Details: if the server stops.

#Reach it from your phone

The Windows install listens only on your PC. Use Tailscale to reach it privately from your phone: tailscale serve --bg 3457 on the PC, then sign in to Docket for Android with the address it gives you.

#Docker server

One script on any Linux machine with Docker sets up Vikunja, Docket web, the AI connector and HTTPS certificates. Full guide: Docker server.

#No public IP or domain

claude.ai and ChatGPT need a public HTTPS address for the connector. Without opening ports, use Tailscale Funnel or a Cloudflare Tunnel: public address for AI.

#Your own Vikunja

Docket works with any Vikunja 2.x server: existing Vikunja.

#Docket web skin

docket-web serves Vikunja's web app with the Docket look. It's included in the Windows and Docker setups: Docket web.
