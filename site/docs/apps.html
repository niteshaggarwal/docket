Using Docket

Docket comes as a Windows app, an Android app, a web app and a command line. They all show the same tasks and behave the same way, because they share one core library: My Day, repeats, quick-add words and subtasks work identically everywhere.

#Windows app

Start menu > Docket. Smart lists, lists and groups, the details pane, boards, people, AI planning and more: the Windows app. Also see keyboard shortcuts and quick add and commands.

#Android app

Sign in with your server's address (for a Windows install, use Tailscale). Swipe right to add to My Day, left to delete: the Android app.

#Web app

Open http://localhost:3457 on the PC with Docket, or your server's address: Docket web.

#docket command line (Windows)

docket shows today's tasks; docket add "Send invoice friday !3" adds one. Every command, with examples and JSON output for scripts: the command line.
