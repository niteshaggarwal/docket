# Keyboard shortcuts

Docket for Windows can be used entirely from the keyboard. The same list is in the app under
**Settings > Keyboard shortcuts**.

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Add a task (jump to the add bar) |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Complete the selected task |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Add the selected task to My Day, or remove it |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Mark the selected task important, or not |
| <kbd>Delete</kbd> | Delete the selected task (with Undo) |
| <kbd>Enter</kbd> | Open the task's details |
| <kbd>Esc</kbd> | Close the details |
| <kbd>→</kbd> / <kbd>←</kbd> | Expand or collapse subtasks |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Search |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | New list |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> or <kbd>F5</kbd> | Refresh |

In the add bar, [quick-add words](quick-add.md) set the date and priority, and <kbd>/</kbd> opens the commands.

On this documentation site, press <kbd>/</kbd> to search.
